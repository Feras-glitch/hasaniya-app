# المنظومة الحسنية — مشروع تطبيق أندرويد (APK)

التطبيق يحوي كل ملفات الموقع داخله (app/src/main/assets/www) ويعمل بلا إنترنت ولا سيرفر.
الميكروفون والنطق والتسميع تعمل عبر خدمات أندرويد نفسها.

## الطريقة الأسهل: بناء الـ APK على GitHub (بلا برامج)
1. أنشئ حسابًا مجانيًا في github.com ثم مستودعًا جديدًا (New repository).
2. ارفع محتوى هذا المجلد كاملًا (Add file > Upload files)، مع المجلد المخفي `.github`.
   إن لم يظهر المجلد المخفي في جهازك فأنشئ الملف يدويًا في GitHub بالمسار `.github/workflows/build-apk.yml` وانسخ محتواه.
3. افتح تبويب Actions > Build APK > Run workflow، وانتظر 5–10 دقائق.
4. من صفحة التشغيل نزّل الملف المرفق `hasaniya-apk` (zip)، فكّه، وثبّت `app-debug.apk` على الجهاز.
   (فعّل «التثبيت من مصادر غير معروفة» عند الطلب.)

## الطريقة الثانية: Android Studio
افتح المجلد، وانتظر Sync، ثم Build > Build APK(s).

## ملاحظات صريحة
- لم أستطع بناء الـ APK ولا اختباره على جهاز حقيقي من بيئتي؛ قد يظهر خطأ بسيط في أول بناء ويُصلح بسرعة، أرسل لي نص الخطأ.
- صوت القراءة يتطلب وجود صوت عربي في «تحويل النص إلى كلام» بالجهاز.
- التعرّف على الصوت (التسميع) يعتمد على خدمة Google للتعرف على الكلام، وقد يحتاج إنترنت.
- التصدير والمشاركة يفتح قائمة المشاركة في أندرويد.
- نسخة debug صالحة للتثبيت المباشر؛ للنشر في المتجر يلزم توقيع release.
