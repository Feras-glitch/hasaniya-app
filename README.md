# المنظومة الحسنية

تطبيق تفاعلي يعمل دون إنترنت لحفظ القسم الأول من المنظومة الحسنية في السيرة النبوية (161 بيتاً، 16 محطة)، للأطفال من 6 إلى 10 سنوات، مع وضع للوالدين والمعلم.

## محتوى المستودع
- `web/` — التطبيق نفسه (HTML وJavaScript)، ومعه الاختبارات (`web/tests`) وأدوات الصور (`web/tools`). سجل الإصدارات في `web/README.md`.
- `android/` — غلاف أندرويد (WebView). ملفات التطبيق تُنسخ إليه من `web/` عند البناء.
- `.github/workflows/build-apk.yml` — يشغّل الاختبارات ثم يبني ملف APK موقّعاً عند كل رفع إلى main.
- `SIGNING-AR.md` — إضافة مفتاح التوقيع (مرة واحدة).

## تشغيل الاختبارات محلياً
```
node web/tests/run-all.js          # اختبارات المحتوى والمنطق
node web/tests/run-all.js --e2e    # مع اختبارات المتصفح (تحتاج playwright وchromium)
```
