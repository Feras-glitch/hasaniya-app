# المنظومة الحسنية

**النسخة:** v114

تطبيق يعمل دون إنترنت لحفظ القسم الأول من المنظومة الحسنية في السيرة النبوية (161 بيتاً في 16 محطة)، للأطفال من 6 إلى 10 سنوات، مع منطقة للوالدين والمعلم. يعمل في المتصفح، وعلى أندرويد (APK)، وويندوز ولينكس.

## المجلدات
| المجلد | ما فيه |
|---|---|
| `web/` | التطبيق نفسه فقط (HTML وJavaScript والمحتوى). هذا ما يُشحن. |
| `tests/` | الاختبارات: `unit/` بلا متصفح، و`e2e/` في المتصفح، و`device/` على هاتف افتراضي، و`data/` ملفاتها. |
| `tools/` | أدوات التطوير: الملف الواحد، ورسم المصحف، والصور، وحزمة الصوت، وتقرير المراجعة، ورقم النسخة، والفحص. |
| `android/` · `desktop/` | غلاف أندرويد (WebView) وغلاف ويندوز ولينكس (Electron). |
| `sources/quran/` | مصدر رسم المصحف (تولَّد منه ملفات الآيات). |
| `docs/` | قائمة فحص الهاتف، و`owner/` وثائق صاحب المشروع (التوقيع وتسجيل Google)، و`archive/` تقارير قديمة. |

## التشغيل
افتح `web/index.html` في المتصفح، أو: `python3 -m http.server -d web` ثم افتح `http://localhost:8000` (ليعمل دون إنترنت بعد أول فتح).

## الاختبار والفحص
```
npm install            # أدوات التطوير بإصداراتها (Playwright وESLint)
npx playwright install chromium
npm test               # اختبارات بلا متصفح (ثوانٍ)
npm run test:e2e       # ومعها اختبارات المتصفح (دقائق)
npm run lint           # فحص الكود مدموجاً بترتيب index.html
```
وأدوات بايثون: `pip install -r requirements-dev.txt`.

## الإصدار
1. `npm run version:bump` يرفع رقم النسخة في كل مواضعه (وإن تغيّر المحتوى فارفع `CONTENT_VERSION`؛ انظر `CONTRIBUTING.md`).
2. الرفع إلى `main`. البناء الآلي (`.github/workflows/build-all.yml`) يفحص تطابق الأرقام، ثم الفحص والاختبارات، ثم يبني أندرويد (APK موقّع) وويندوز ولينكس والملف الواحد والويب، ثم يختبر على هاتف افتراضي، وبعد نجاحها كلها تُنشر في **Releases** بوسم `vرقم-النسخة`.
3. **مهم:** إن كان وسم النسخة موجوداً لالتزام آخر فلا يُنشر شيء (لا تُستبدل نسخة نزّلها الأهالي). لنشر تعديل جديد ارفع رقم النسخة.
