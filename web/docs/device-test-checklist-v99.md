# قائمة الفحص على الجهاز — v99 (محدّثة لـ v104)

صار أكثر القائمة يُختبر آلياً مع كل رفع إلى GitHub. هذا الملف يبيّن أين يُختبر كل بند، وما بقي ليُجرَّب باليد.

**أين تُرى النتائج:** صفحة المستودع ← **Actions**:
- **Build all:** كل اختبارات المحتوى والمنطق والمتصفح، ثم بناء كل النسخ، ثم اختبار الهاتف الافتراضي (نتيجته جدول في صفحة التشغيل، والصور في **Artifacts ← device-screens**)، ثم النشر في **Releases**.

**مفتاح الأعمدة:**
- **متصفح:** اختبار آلي في Build all.
- **هاتف افتراضي:** اختبار Device test.
- **يدوي:** يحتاج يدك أو أذنك.
