# قائمة الفحص على الجهاز — v99

صار أكثر القائمة يُختبر آلياً مع كل رفع إلى GitHub. هذا الملف يبيّن أين يُختبر كل بند، وما بقي ليُجرَّب باليد.

**أين تُرى النتائج:** صفحة المستودع ← **Actions**:
- **Build APK:** كل اختبارات المحتوى والمنطق والمتصفح، ثم بناء التطبيق الموقّع.
- **Device test:** هاتف أندرويد افتراضي. النتيجة جدول في صفحة التشغيل، والصور في **Artifacts ← device-screens**.

**مفتاح الأعمدة:**
- **متصفح:** اختبار آلي في Build APK.
- **هاتف افتراضي:** اختبار Device test.
- **يدوي:** يحتاج يدك أو أذنك.

## ما بقي يدوياً (نحو 10 دقائق، على هاتف حقيقي)

ثبّت التطبيق من Actions ← Build APK ← Artifacts ← hasaniya-apk، ثم جرّب:

| # | الخطوة | المتوقع | النتيجة |
|---|---|---|---|
| أ | افتح بيتاً واضغط «🔊 استمع» | النطق واضح، والوقف عند آخر البيت صحيح | |
| ب | سجّل بيتاً بصوت الطفل ثم استمع | الصوت واضح ومسموع | |
| ج | من «للوالدين» ← «🎙️ استوديو التسجيل» ← «التسجيل المتتابع»: سجّل ثلاثة نصوص من «التعليمات ورسائل ناجي» | الزر يتحوّل إلى «أوقف» ثم «أعد التسجيل»، و«استمع» يُسمعك صوتك | |
| ج٢ | في الاستوديو اختر «خيارات الأسئلة» وسجّل خياراً، ثم افتح اختبار تلك المحطة | يُقرأ السؤال آلياً ثم يُسمع الخيار بصوتك، وزر 🔊 بجانبه يُسمعه وحده | |
| ج٣ | في الاستوديو ← «أسماء الأطفال» سجّل «يا (اسم طفلك)»، ثم عُد للطفل وأخطئ في ترتيب بيت | يُسمع الاسم بصوتك قبل رسالة ناجي | |
| ج٤ | من «المستخدمون» ← ✎ فعّل «وضع الطفل الصغير» (يطلب الرقم السري)، ثم افتح «مراجعة» ← الألغاز | الأزرار أكبر، واللغز بثلاثة أجوبة تُسمع، بلا كتابة | |
| د | في الاستوديو ارفع ملف صوت من ملفات الهاتف | يظهر الملف في نافذة الاختيار ويُقبل | |
| هـ | «💾 نسخة احتياطية» ثم احفظها في الملفات، ثم «📥 استعادة» واختر الملف | يظهر الملف في نافذة الاختيار، ثم تأكيد الاستعادة | |
| و | تصفّح المحطات وانظر إلى الصور والقصص | الشكل مريح والصور واضحة | |
| ز | سجّل عدة أبيات ثم افتح «تسجيلاتي» | الاستعراض سريع | |

اكتب في الملاحظات نوع الهاتف ونسخة أندرويد، وأي سلوك غريب.
