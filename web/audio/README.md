# مجلد الصوت المضمّن

هنا يوضع `voice-pack.zip`: تسجيل بشري للأبيات يسمعه الطفل من أول يوم بدل القارئ الآلي.

- لا يُوضع الملف باليد. تبنيه الأداة من حزمة صدّرها القارئ من «استوديو التسجيل» في التطبيق:
  `node tools/bundle-voice-pack.js <ملفات الحزمة>` (من مجلد web).
- الأداة تكتب بصمة الملف في `BUNDLED_VOICE_ID` داخل `js/config.js`، وترفض أي تسجيل لا يطابق النص الحالي.
- يُسجَّل بعد اعتماد التشكيل، لأن تغيير حركة في بيت يُبطل تسجيله.
- الحذف: `node tools/bundle-voice-pack.js --remove`.
